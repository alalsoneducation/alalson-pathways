# صور البرامج والدبلومات

ضع هنا صورة كل خدمة تعليمية باسم يطابق حقل `image` في `src/data/programs.ts`.

مثال: البرنامج `english-diploma` يبحث عن `/images/programs/english-diploma.jpg`.

- المقاس المفضل: 1200×750 بكسل (نسبة 16:10)
- الصيغة: jpg أو webp (أقل من 300KB)
- إن لم تُرفع الصورة يظهر بديل احترافي بهوية المعهد تلقائياً
- للشعارات استخدم `imageFit: "contain"` في بيانات البرنامج
